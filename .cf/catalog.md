**Description:**

Caravel is a versatile and comprehensive template System on Chip (SoC) designed specifically for the Efabless chipIgnite program. This reference design provides a robust framework for creating custom chips, leveraging cutting-edge open-source technologies within the SkyWater 130nm process node.

The Caravel architecture integrates essential components, including a RISC-V processor, Wishbone bus interface, and various I/O peripherals such as GPIO, SPI, and UART. It features a dedicated user project area that allows designers to seamlessly integrate their custom intellectual property (IP) and tailor the design to meet specific application requirements.

With its structured project organization, Caravel simplifies the development process, enabling efficient verification and simulation of designs. The template supports both FPGA and ASIC implementations, making it an ideal choice for a wide range of applications in embedded systems.

For more detailed information on implementation and integration, refer to the [Caravel User Project Documentation](https://caravel-user-project.readthedocs.io/). This resource provides guides and best practices for optimizing your project within the Caravel framework.

Explore the possibilities of custom chip design with Caravel and take advantage of its seamless integration with the chipIgnite program's multi-project wafer (MPW) shuttles for open-source chip fabrication.
